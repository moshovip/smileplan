# SmilePlan — Контент и SEO-стратегия

## SEO-статейник (методология Артемия)

**Цель:** органический трафик врачей-стоматологов из Яндекса и Google.
**Целевые запросы:** "MIS для стоматологии", "программа для записи пациентов", "бесплатная медицинская карта стоматолога", "как вести медкарту стоматолога".

### Семантическое ядро (черновик)

**Коммерческие запросы (горячие):**
- "mis для стоматологии бесплатно"
- "программа для стоматологической клиники"
- "электронная медкарта стоматолога"
- "crm для стоматологии"

**Информационные запросы (статьи):**
- "как вести медкарту в стоматологии"
- "форма 043 стоматология образец"
- "план лечения стоматологического пациента"
- "как организовать расписание приёмов в стоматологии"
- "что такое MIS для стоматологии"

### Контент-план (типы статей)

1. **Гайды** — "Как заполнять медкарту: пошаговое руководство для стоматолога"
2. **Сравнения** — "Инфодент vs SmilePlan: что выбрать небольшой клинике"
3. **Кейсы** — "Как частный стоматолог перешёл с тетради на цифровую MIS"
4. **Обзоры** — "Топ-5 MIS для стоматологии в 2026 году"
5. **FAQ** — "Ответы на частые вопросы об электронных медкартах"

### Платформы публикации

- Собственный блог (GitHub Pages)
- VC.ru (карточки с ссылкой)
- Яндекс.Дзен
- Медицинские форумы (doctorinfo.ru, стоматологические сообщества)

## SEO-скилл (автоматизация)

Планируется адаптация методологии Артемия:
- 16 этапов обработки статьи
- 25 субагентов параллельно
- Автоматическая публикация на VC, Дзен
- ~60 мин на статью, ~3 копейки себестоимость
- Оценка трафика по каждой статье еженедельно

→ Реализовать через Claude-скилл `/seo-article`
