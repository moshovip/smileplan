# SmilePlan — Продукт

## Что это

**SmilePlan** — Progressive Web App (PWA) для стоматологических клиник. Работает в браузере, данные хранятся локально (IndexedDB). Не требует сервера, установки, IT-специалиста.

## Ключевые модули

| Модуль | Что делает |
|---|---|
| **Пациенты** | База пациентов, фото, аллергии, источник прихода |
| **Медкарта** | Записи по визитам: жалобы, осмотр, диагноз, лечение, следующий визит |
| **Планирование лечения** | Зубная формула, план по зубам с ценами |
| **Календарь** | Расписание приёмов, статусы (записан → пришёл → лечение → оплачено) |
| **Прайс** | Редактируемый прайс-лист услуг |
| **Финансы** | Список всех оплат, фильтры |
| **Роадмап** | Персональный план лечения пациента |

## Технический стек

- React 18 + Vite 5 + TailwindCSS 3
- Zustand (стейт-менеджмент)
- IndexedDB через idb (локальное хранилище, DB_VERSION=5)
- GitHub Pages (хостинг, бесплатный)
- SPA-роутинг через 404.html redirect

## Конкурентные преимущества

1. **Бесплатно** — работает на GitHub Pages, нет серверных расходов
2. **Офлайн** — данные локально, не зависит от интернета
3. **Быстрый старт** — никакой установки, открыл браузер и работаешь
4. **Медкарты с голосовым вводом** — диктовка прямо в полях

## Ограничения текущей версии

- Нет синхронизации между устройствами (данные только в одном браузере)
- Нет резервного копирования в облако
- Нет мультипользовательского режима
- Только один врач / одна клиника
