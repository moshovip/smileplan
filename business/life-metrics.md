# SmilePlan — Live Metrics

Вместо хардкода цифр в файлах business/ используй маркер **LIVE** и ссылку сюда.

## Подключение

**ВАРИАНТ D (сейчас): вручную обновляется раз в неделю.**

Обновляй по понедельникам после проверки GitHub Pages Analytics (если подключены) и Яндекс.Метрики.

## Метрики

### Трафик на GitHub Pages
- Маркер: **LIVE**
- Источник: Яндекс.Метрика / GitHub Insights
- Формат: уникальных посетителей / день

### Количество установок (PWA)
- Маркер: **LIVE**
- Источник: Google Search Console / Analytics events
- Формат: число

### Публикации в SEO-статейнике
- Маркер: **LIVE**
- Источник: подсчёт файлов в blog/ папке или CMS
- Формат: число статей / трафик с поиска

### Платящие пользователи
- Маркер: **LIVE**
- Источник: CloudPayments / ЮКасса личный кабинет
- Формат: число активных подписок
