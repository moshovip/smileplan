# SmilePlan — Второй мозг бизнеса

**Проект:** SmilePlan — MIS (медицинская информационная система) для стоматологических клиник.

**В одном предложении:** SaaS-приложение для стоматологов, заменяющее тетрадки и Excel: запись пациентов, медкарты, планы лечения, финансы — всё в одном браузере, без установки.

При работе читай только нужный файл, не загружай всё сразу.
