# SmilePlan — Возражения

## Топ возражений (до покупки)

### 1. "А данные не потеряются?"
**Суть:** Страх потерять базу пациентов, которую вёл годами.
**Ответ:** Данные хранятся в браузере на устройстве врача. Есть экспорт. Советуем делать резервные копии.
**Что улучшить в продукте:** Сделать автоматический экспорт / бекап.

### 2. "Это бесплатно — значит ненадёжно"
**Суть:** Недоверие к бесплатным инструментам для профессиональной деятельности.
**Ответ:** Open-source, код на GitHub. Используют реальные врачи. Нет серверных расходов — поэтому бесплатно.

### 3. "У меня уже есть [Excel / тетрадь / 1С]"
**Суть:** Инерция. Менять то, что привык.
**Ответ:** Можно перенести данные. Попробуй рядом — без удаления старого.

### 4. "Нет синхронизации между устройствами"
**Суть:** Хочет работать и с компьютера, и с телефона.
**Ответ:** В работе. Пока — один основной браузер.
**Что улучшить:** Облачная синхронизация — приоритет №1 для Pro.

### 5. "Нет поддержки, если что-то сломается"
**Суть:** Нет уверенности в том, кто поможет.
**Ответ:** Telegram-канал, GitHub Issues. Для платных — приоритетная поддержка.

### 6. "Мне нужно несколько врачей / несколько кресел"
**Суть:** Маленькие клиники растут, нужен мультипользовательский режим.
**Ответ:** В роадмапе. Пока — один аккаунт на устройство.
