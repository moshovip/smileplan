# SmilePlan - контекст для внешних ИИ (GPT, Gemini и любых других)

Этот файл нужен, чтобы любой ИИ-помощник за одну ссылку понял проект
и выдал результат, который вставится в код без переделки.

Репозиторий публичный: https://github.com/moshovip/smileplan
Живое приложение: https://moshovip.github.io/smileplan/

## Что за проект

SmilePlan - бесплатная PWA для стоматологов. Работает в браузере, данные
лежат локально в IndexedDB, хостинг на GitHub Pages. Заменяет тетрадь и Excel:
пациенты, медкарты, план лечения со сметой, календарь, финансы.

Автор - практикующий врач-стоматолог. Приложением пользуются 5-10 человек,
их обратная связь и определяет приоритеты.

## Стек

React 18 + Vite 5 + TailwindCSS 3, состояние Zustand + IndexedDB (idb).
Ветка `main` - исходники, ветка `gh-pages` - собранная версия.

## Что сейчас нужно от внешнего ИИ

Главная задача - **рисунки зубов**. Всё остальное уже работает.

### Требования к SVG зубов

Без выполнения этих правил файл не вставится, придётся переделывать.

1. **32 файла**, имена по FDI: `18.svg`, `17.svg`, … `28.svg`, `31.svg`, … `48.svg`
2. Одинаковый `viewBox` у всех, рекомендуется `0 0 100 220`
3. Внутри **только `<path>`**. Никаких `<image>`, никакого текста, никаких
   растровых вставок
4. **Не трассировать растр.** Признак трассировки - тысячи мелких команд вида
   `M31 81h1v1h-1Z` и файл на 30+ КБ. Нормальный зуб - 1-2 КБ и десяток команд
   с кривыми `C`. Трассированные файлы нельзя перекрасить и масштабировать
5. Ориентация: верхние зубы (1x, 2x) - **корни вверху**, коронка внизу;
   нижние (3x, 4x) - зеркально
6. Единый масштаб для всех зубов: моляр шире резца, но холст один
7. Обводка одним цветом, заливка белая или отсутствует

### Чего рисовать НЕ надо

Коронку, обточку, канал, имплант, абатмент, вкладку, кость и синус рисовать
не нужно. Эти слои строятся программно от контура зуба: код находит линию
шейки и считает геометрию от неё. Нужен **только контур натурального зуба**.

Благодаря этому рисунок можно менять когда угодно - слои пересчитаются сами.

## Как результат попадает в проект

Внешний ИИ отдаёт файлы человеку, человек передаёт их в сессию Claude Code,
она вставляет их в `web/src` и деплоит. Прямого доступа на запись
в репозиторий у внешнего ИИ нет.

## Правила, которые нельзя нарушать

1. **Ничего не выдумывать в плане лечения.** Позиции, зубы, цены и суммы -
   только те, что дал врач. Нет данных - оставить пусто.
2. Персональные данные пациентов в репозиторий не кладутся.
3. Ключи и токены - только через переменные окружения.
