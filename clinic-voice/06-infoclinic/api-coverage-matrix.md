# Матрица покрытия API «Инфодента»

Заполняется после получения документации от вендора. До пилота не нужна —
разбор консультаций от API не зависит.

Доступ выдаётся по договору: домен МИС плюс ключ домена. Публичного описания
методов нет, часть функций включается платными тарифными опциями.

| Создание, перенос, отмена визита | | | |

## Зачем это нужно потом

Связать качество консультации с исходом: закрылся план или нет, дошёл ли
пациент до оплаты. На пилоте то же самое делается вручную за полчаса на сотню
консультаций.
