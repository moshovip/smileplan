# Пилот: анализ консультаций в 4 кабинетах

## Границы

| Входит | Не входит |
|---|---|
| Запись первичных консультаций в 4 кабинетах | Запись лечебных приёмов |
| Расшифровка с разделением врач — пациент | Голосовое заполнение карты |
| Анализ по чек-листу клиники | Любая запись данных в «Инфодент» |
| Отчёт по каждой консультации врачу | Голосовые команды программе |
| Сводка по четырём врачам для разбора | KPI и финансовая статистика — они в клинике уже есть |

Главное следствие: пилот не зависит ни от кого за пределами клиники. Ни доступа
к API, ни тарифных опций вендора, ни лицензий.

## Какие четыре кабинета

Два врача с сильными консультациями и два со средними или слабыми. Если взять
четырёх сильных, разброса не будет и сравнивать будет не с чем. Дальше слабых
подтягивают на их же записях — это работает лучше общего тренинга, потому что
разбираются реальные разговоры.

## Что происходит на приёме

Врач нажимает «Начать» и в конце «Завершить». Больше ничего. Микрофон стоит на
столе у компьютера и пишет всех сразу — надевать нечего, значит и забыть нечего.

ФИО вслух не называется: запись знает кабинет, дату и время, этого достаточно,
чтобы сопоставить её с расписанием потом.

## Цепочка обработки

```
Кнопка «Начать»
  → запись идёт, файл на компьютере кабинета
  → кнопка «Завершить»
  → распознавание речи
  → разделение говорящих (2–4 человека)
  → анализ по критериям чек-листа
  → отчёт в папку врача (markdown)
  → накопление для недельной сводки
Аудио удаляется через 7–14 дней
```

## План на четыре недели

| Неделя | Что делаем | Чем заканчивается |
|---|---|---|
| 1 | Микрофоны, распознавание и разделение голосов, приложение в кабинетах, перевод чек-листа в критерии | первые 5–10 записей разобраны |
| 2 | Работаем на всех четырёх, правим формулировки критериев | накоплено 25–30 записей для калибровки |
| 3 | Калибровка с человеком, доводка до порогов | оценкам можно верить, отчёты идут врачам |
| 4 | Набор данных, первая сводка, разбор на собрании | решение о масштабировании |

За четыре недели набирается 100–150 разобранных консультаций. Для выводов по
четырём врачам этого достаточно.

## Роли

| Кто | Что делает | Сколько времени |
|---|---|---|
| Ответственный за пилот | следит, что записи идут, собирает обратную связь, ведёт калибровку | 3–4 часа в неделю |
| Знаток методики | переводит чек-лист в критерии, размечает записи на калибровке | 1 день плюс 4 часа |
| Системный администратор | установка на компьютеры | 2–3 дня |
| Разработка | программный контур | 2–3 недели |
| Четыре врача | нажать кнопку | минута в день |

Последняя строка принципиальная. Если от врача требуется больше минуты в день,
пилот затихнет на второй неделе.

## Критерии успеха

| Критерий | Порог |
|---|---|
| Доля консультаций, которые вообще записались | не менее 80 % от проведённых |
| Совпадение оценки ИИ с человеком | не менее 85 % |
| Врачи читают свои отчёты | трое из четырёх регулярно |
| Разброс между врачами виден и объясним | да или нет |
| На собрании разобрали конкретные записи | хотя бы одно собрание |

Первая строка важнее всех остальных. Если записей мало — дело не в технологии,
а в том, что люди не нажимают кнопку, и понять это нужно на первой неделе.

## Что решаем по итогам

1. Расширяем на 12 кабинетов — докупаются только микрофоны.
2. Остаёмся на четырёх и углубляемся: подключаем методику из лекций, связываем
   разбор с исходами через «Инфодент».
3. Закрываем. Железо остаётся клинике и годится под любую другую задачу.

Третий вариант нужно назвать вслух на старте. Пилот, из которого нельзя выйти,
перестаёт быть пилотом и превращается в обязательство, которое саботируют.
