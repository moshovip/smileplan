# Голосовой разбор консультаций — рабочий репозиторий проекта

Проект стоматологической клиники: запись первичных консультаций на Plaud,
расшифровка с разделением говорящих и автоматический разбор по чек-листу клиники.

Цель — понять, **на каком этапе консультации теряется пациент** и что именно
в этом зависит от врача, а что от качества входящего потока.

## Где что лежит

| Папка | Что внутри |
|---|---|
| `00-context/` | зачем всё это, принятые решения, открытые вопросы |
| `01-pilot/` | гайд по пилоту на 4 кабинета, железо, бюджет, обработка |
| `02-checklists/` | исходный чек-лист клиники и машинные критерии к нему |
| `03-analysis/` | формат отчёта, метрики разговора, процедура калибровки |
| `04-legal/` | зона клиники: здесь только отметка о разграничении |
| `05-business/` | материалы для учредителя и руководства |
| `06-infoclinic/` | интеграция с МИС — следующий этап, после пилота |
| `07-methodology/` | материалы обучения по управлению: точки контакта, карты, оригиналы снимков |
| `prompts/` | готовые промпты для разбора консультаций и сборки чек-листов |
