# Чем машинная версия отличается от исходника

Исходник — документ клиники, он не меняется. Здесь объяснено каждое расхождение.

| Пункт | Что изменено | Почему |
|---|---|---|
| 1 | Оценивается только приветствие, без улыбки | улыбку по аудио не слышно |
| 3 | Выведен из автоматической части | высота кресла не определяется по звуку |
| 8 | Разложен на три признака: не перебивал, ответил на вопросы, нет стоп-фраз | исходная формулировка оценочная, машина начнёт выдумывать |
| 10 | Разбит на четыре отдельных счётчика С, П, И, Н | иначе непонятно, какого типа вопросов не хватает |
| 11 | Выведен из автоматической части | контакт глазами не слышен |
| 16е | Проверяется по карте | если врач не проговаривает съёмку, по аудио её нет |
| 17 | Убрано «была ли необходимость» | клиническое суждение остаётся за врачом |
| 18 | Проверяется частично | порядок восстанавливается, только если врач его проговаривает |
| 20ж | Считается по таймкодам | человек на слух это не измеряет, машина измеряет точно |
| 24в | Добавлен признак «пациент не вернулся к возражению» | иначе «отработал» не отличить от «проговорил» |

## Что машина считает точнее человека

Число обращений по имени-отчеству, число вопросов каждого типа, порядок
упоминания сумм, число вариантов плана, длительность обсуждения одной проблемы,
наличие стоп-фраз, пояснение термина рядом с термином.
