# Открытые вопросы

Закрывайте по мере получения ответов, отмечайте дату и источник.

## По Plaud

- [ ] Есть ли тариф с лимитом больше 1200 минут в месяц для нашего региона
- [ ] Что происходит при исчерпании лимита: очередь до следующего месяца или докупка пакетом
- [ ] Сколько аккаунтов берём и как они распределяются по кабинетам
- [ ] Можно ли выгрузить с устройства само аудио — нужно для запасного варианта с локальной расшифровкой
- [ ] Качество разделения говорящих на русском при трёх-четырёх участниках
- [ ] Точность распознавания номеров зубов до и после настройки словаря

## Блокирующие пилот

- [ ] Формулировка в ИДС: покрывает ли действующее согласие на аудио- и
      видеофиксацию именно аудиозапись консультации и её анализ для контроля качества
- [ ] Письменное согласие на трансграничную передачу и уведомление Роскомнадзора —
      без этого запись через Plaud начинать нельзя
- [ ] Какие четыре кабинета и какие четыре врача (двое сильных, двое слабых)
- [ ] Кто исполняет роль ответственного за пилот

## Нужны для расчётов

- [ ] Сколько первичных консультаций в месяц по клинике
- [ ] Какая доля заканчивается составленным планом
- [ ] Какая доля планов доходит до оплаты и лечения
- [ ] Средний чек плана лечения
- [ ] Рекламный бюджет в месяц и разбивка по источникам
- [ ] Есть ли в «Инфоденте» пометка источника пациента
- [ ] Видна ли сейчас разница конверсии между врачами

## По точкам контакта

- [ ] Записываются ли сейчас звонки администраторов и где хранятся
- [ ] Выясняет ли администратор повод обращения или записывает всех подряд
- [ ] Есть ли речевой стандарт первой фразы при ответе на звонок
- [ ] Нарисовать карту цепочки первичного пациента с той же глубиной дробления

## Методические

- [ ] Вычитка машинных критериев носителем методики
- [ ] Пороги итоговой оценки консультации и список критичных пунктов
- [ ] Чек-лист по методике консультаций из лекций — делается отдельно
