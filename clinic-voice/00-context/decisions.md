# Принятые решения

Каждое решение с причиной. Если предлагаете отойти — сначала прочитайте причину.

| Решение | Почему |
|---|---|
| **Запись и расшифровка — Plaud Pro** | куплено и решено клиникой; снимает разработку распознавания и разделения говорящих |
| Plaud закрывает запись и расшифровку, разбор и сводки остаются нашим слоем | шаблон Plaud выжимает одну консультацию, но не даёт цитату с таймкодом на каждый из 45 критериев и не сравнивает врачей между собой |
| На пилоте пишем выборку, а не все консультации подряд | лимит 1200 минут на аккаунт Pro; сплошная запись требует вдесятеро больше минут, а для выводов хватает 100–150 разобранных записей |
| Фамилия пациента не звучит в записи и не попадает в имя файла | минимизация данных, уходящих за границу; привязка делается по расписанию внутри клиники |
| Записываем только первичные консультации | под бормашиной запись всё равно негодная, данных больше, риска больше, ценности меньше |
| Устройство записи стоит на столе у компьютера, а не на враче | консультация идёт за компьютером; нечего надевать — нечего забыть |
| Врач не называет ФИО вслух | лишнее действие, которое будут забывать; запись знает кабинет, дату и время, этого хватает для сопоставления с расписанием |
| Два действия врача за приём: «Начать» и «Завершить» | если требуется больше минуты в день, пилот затихает на второй неделе |
| Аудио хранится 7–14 дней, расшифровка и отчёт — markdown навсегда | аудио нужно только чтобы послушать спорный момент на собрании |
| Оценка без цитаты и таймкода не ставится | единственная защита от выдумок и единственный способ снять спор на собрании |
| Три градации вместо галочки: прозвучало / формально / не прозвучало | двоичная отметка слишком грубая и вызывает споры |
| В пилот берём двух сильных и двух слабых врачей | четыре сильных не дадут разброса, сравнивать будет не с чем |
| Пилот не зависит от API «Инфодента» | доступ выдаёт вендор по договору, сроки вне нашего контроля; разбор консультаций работает без него |
| Алиса исключена | потребительский сервис без режима обработки данных по поручению оператора |
| Разбор по тексту: место выбирает клиника | после решения по Plaud текст и так проходит через зарубежный контур; критично другое — чтобы в тексте не было прямых идентификаторов |
| Своего сервера и микрофонов не покупаем | Plaud закрывает запись и расшифровку; вместо капитальных затрат — подписка |
| Разборы не влияют на оплату и аттестацию | условие участия врачей; иначе начнут работать на микрофон |

## Отменённые решения

| Что было | Что вместо |
|---|---|
| Настольный USB-микрофон, 4 штуки | устройства Plaud |
| Три варианта размещения: свой компьютер, аренда в РФ, своё железо | расшифровка в Plaud, разбор по тексту |
| Whisper, pyannote, WhisperX своими силами | расшифровка и разделение говорящих приходят готовыми |
| Отчёт через 10–15 минут после приёма | отчёты по дню готовы вечером, после синхронизации устройств |
