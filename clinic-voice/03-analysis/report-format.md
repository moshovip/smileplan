# Формат отчёта по консультации

Одна страница, читается за минуту. Структура одинаковая для всех, чтобы отчёты
складывались в недельную сводку.

## Разделы

**Шапка** — дата, врач, кабинет, длительность, повод обращения словами пациента.

**Чек-лист** — каждый пункт: отметка, цитата, таймкод. Пункты со статусом
«неприменимо» показываются отдельным списком внизу, чтобы не портить картину.

**Ход разговора** — доля речи врача и пациента, минута первого упоминания цены,
число открытых вопросов, число вариантов плана.

**Возражения** — цитата, тип, был ли ответ по существу, возвращался ли пациент
к этой теме позже.

**Что пациент сказал между строк** — фраза, за которой стоит больше, чем звучит,
с расшифровкой смысла и таймкодом.

**Чем закончилось** — договорённость с датой или отметка, что её не было.

**Итоговая оценка** — одна строка, считается прозрачно.

## Итоговая оценка

Доля пунктов со статусом «прозвучало» от применимых, плюс два обязательных
условия: все возражения отработаны и есть закрытие с датой.

| Оценка | Условие |
|---|---|
| Отлично | не менее 90 %, возражения закрыты, есть следующий шаг с датой |
| Хорошо | 75–90 %, критичные пункты на месте |
| Есть над чем работать | 50–75 % или нет закрытия |
| Требует разбора | менее 50 % или возражения повисли без ответа |

Пороги и список критичных пунктов задаёт клиника при настройке, не ИИ.

## Кто что видит

Врач — только свои консультации. Ответственный за пилот — сводку по всем
четырём. На период пилота разборы не выходят за эти пределы и не влияют на
оплату и аттестацию.
