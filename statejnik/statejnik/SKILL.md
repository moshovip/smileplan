# Скилл статей - навык написания SEO-статей

Запускает полный процесс написания и публикации SEO-статьи по методологии **16 этапов** (`methodology/00-methodology-16-stages.md`).

## Перед первым запуском

Должен быть заполнен `config.yaml` (домен, аудитория, голос, оффер, стоп-слова, способ публикации). Если его нет - сначала прогнать `AUTOPILOT.md` (он соберёт конфиг, изучив проект).

## Когда триггериться

- «Напиши статью про <тему>» - тема задана, начать с Этапа 3 (заголовок).
- «Запусти Скилл статей» / «нужна новая статья» - темы нет, начать с Этапа 1 (автономный выбор темы).
- «Построй статью», «новая SEO-статья», «статья в блог про X».

**НЕ триггериться:** правка уже опубликованной статьи (это ручной Edit + переиндексация), общий вопрос «как устроен Скилл статей» (ответ из методологии без запуска).

## Главное правило - autonomous mode

Любой запуск = автономный режим. Агент не ждёт «ОК» между этапами, доводит статью до публикации, пишет ретроспективу и завершает. Останавливается только в 4 случаях (gate-условия):

1. **Тема слабая** (балл ниже порога по 9 осям) → не пишем, берём в backlog, завершаем.
2. **Критичное QA-нарушение** (выдуманная цитата/цифра, нарушение `editorial.banned_words`, обещание гарантированного результата) не закрылось за 3 итерации автоисправления → статья остаётся черновиком, пишем причину.
3. **Визуальная проверка рендера** провалилась дважды подряд → черновик, пишем что сломано.
4. **Публикация через `cms.adapter`** вернула ошибку → пишем traceback и состояние, чините руками.

Во всех остальных случаях - продолжаем, не спрашиваем.

## Что делать при активации

1. Прочитать `config.yaml`, `methodology/00-methodology-16-stages.md` (целиком), `checklists/`.
2. Если есть `voice.source` - прочитать образцы голоса для тон-матчинга.
3. Создать рабочий чек-лист из `checklists/_CHECKLIST-TEMPLATE.md` → `work/<slug>.checklist.md` (Этап 0a).
4. Идти по 16 этапам сверху вниз, не пропуская, закрывая пункты чек-листа только при наличии артефакта в `work/<slug>/`.
5. Финальный gate перед завершением: `grep -c "\[ \]" work/<slug>.checklist.md` = 0.

Полный процесс - в `methodology/00-methodology-16-stages.md`.
