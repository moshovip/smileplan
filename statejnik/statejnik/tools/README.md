# Инструменты «Скилла статей» - измеримые проверки и публикация

Переносимые скрипты, которые превращают «на глаз вроде нормально» в число и доводят статью до публикации. Запускаются в **вашем** проекте, на **ваших** статьях, без внешней инфраструктуры. Только стандартная библиотека Python 3 (3.7+), ставить ничего не нужно.

## Проверки текста (Фаза 4 - валидация)

| Скрипт | Что проверяет |
|---|---|
| `originality-check.py` | Оригинальность черновика против корпуса опубликованного (TF-IDF косинус + совпадающие n-граммы) |
| `read-aloud-check.py` | Читаемость вслух: длинные предложения, скопления согласных, длинные слова, канцелярит, голые цифры |
| `ai-cadence-check.py` | AI-почерк: симметрии «не X, а Y», «это не А. это Б», одиночные слова через точку, литобороты, канцелярит, длинное тире |
| `structure-check.py` | Структура: ровно один H1, непустые H2, блок источников, CTA на оффер, alt у картинок, внутренние ссылки |

## Публикация (Этапы 9-12)

| Скрипт | Что делает |
|---|---|
| `publish.py` | Публикация через `cms.adapter`. В коробке - адаптер `manual` (кладёт файл в `published/`). Остальные (wordpress/ghost/notion/custom) - точки расширения под ваш CMS |
| `preview.py` | `check --url` проверяет, что превью отдаёт HTTP 200 (а не 500 от сломанного рендера) до публикации на прод |

`_config.py` - общий загрузчик `config.yaml`, нужен всем скриптам проверки; держите его рядом в `tools/`.

Каждый скрипт возвращает код выхода, так что их легко встроить в gate или CI: ненулевой код = есть на что посмотреть.

## Зависимости

**Только стандартная библиотека Python 3** (3.7+). Ни `numpy`, ни `scikit-learn` (TF-IDF и косинус посчитаны на чистом Python), ни `PyYAML` (`config.yaml` читается встроенным мини-парсером). Если PyYAML у вас уже стоит - подхватится автоматически, он точнее на сложных конфигах.

Проверить, что всё запускается:

```bash
for t in originality-check read-aloud-check ai-cadence-check structure-check; do
  python3 tools/$t.py --help >/dev/null && echo "ok: $t"
done
```

## Конфигурация (`config.yaml`)

Пороги берутся в порядке: **флаг CLI -> `config.yaml` -> встроенный дефолт**. Указывать конфиг не обязательно: скрипты сами подхватят `./config.yaml` (или передайте `--config путь`).

```yaml
tools:
  originality:
    max_cosine: 0.60      # косинус выше = клон-риск (FAIL)
    max_ngram: 0.30       # Jaccard по n-граммам выше = дословные совпадения (FAIL)
    ngram_n: 5            # длина словесной n-граммы
  read_aloud:
    max_sentence_words: 40  # длиннее = флаг «режь на дыхание»
  cadence:
    max_per_1k: 3.0       # суммарная плотность AI-маркеров на 1000 слов
  structure:
    min_internal_links: 1 # минимум ссылок на ваши же материалы

voice:
  source: "./voice-samples"   # ваша папка с образцами текста (опц.) - для калибровки
                              # порога каденции под ваше живое письмо
```

Дефолты разумные - можно вообще без `config.yaml`.

## `originality-check.py`

Сравнивает черновик с корпусом и говорит, насколько вы повторяете уже опубликованное. Считает метрики против **каждого** файла корпуса и берёт самый похожий.

```bash
python3 tools/originality-check.py work/<slug>/draft.md published/
python3 tools/originality-check.py work/<slug>/draft.md published/ --max-cosine 0.45 --json
```

Вердикт **PASS**, если `cosine <= max_cosine` И `ngram <= max_ngram`. Иначе **FAIL** + список совпавших n-грамм. Если черновик и корпус на разных алфавитах - вердикт `CROSS_LANG`, решение за человеком.

Коды выхода: `0` PASS · `1` FAIL · `2` разные языки · `3` корпус/ввод непригоден.

## `read-aloud-check.py`

Механическое сито «на язык»: длинные предложения, скопления согласных, длинные слова, канцелярит, голые цифры. Заточено под русский. Это **не блокер**, а список на правку (`REVIEW`, код 1). Финальный судья - чтение вслух человеком.

```bash
python3 tools/read-aloud-check.py work/<slug>/draft.md
```

Коды выхода: `0` чисто · `1` есть флаги.

## `ai-cadence-check.py`

Ловит то, что вычитка пропускает: накопительную плотность симметрий и шаблонов генерации. Считает **плотность маркеров на 1000 слов**. Длинное тире - отдельный hard-флаг. Этот же скрипт закрывает AI-detection аудит (Этап 15) - сохраните его вывод в `work/<slug>/etap-15-audit.md`.

```bash
python3 tools/ai-cadence-check.py work/<slug>/draft.md
# калибровка порога по вашим текстам:
python3 tools/ai-cadence-check.py --baseline-dir ./voice-samples/
```

Вердикт **REVIEW** (код 1), если плотность выше `max_per_1k` ИЛИ найдено длинное тире. Иначе **CLEAN**.

## `structure-check.py`

Механические структурные проверки черновика: ровно один H1, непустые разделы H2, наличие блока источников, ссылка на `cta.url`, alt у всех картинок, минимум внутренних ссылок. Советующая (`1` = есть замечания). TL;DR в каждом H2 и атрибуцию цитат проверяйте глазами - регексом ненадёжно.

```bash
python3 tools/structure-check.py work/<slug>/draft.md
```

Коды выхода: `0` структура в порядке · `1` есть замечания.

## `publish.py`

Публикует статью через выбранный `cms.adapter`.

```bash
python3 tools/publish.py --adapter manual --slug <slug> --status draft work/<slug>/draft.md
python3 tools/publish.py --adapter manual --slug <slug> --status published work/<slug>/draft.md
```

Адаптер `manual` кладёт файл в `published/<slug>.md` с проставленным статусом. Адаптеры `wordpress` / `ghost` / `notion` / `custom` - точки расширения: впишите вызов API вашего CMS в соответствующую функцию. **Тело передавайте структурированными полями, не сырой строкой** - так вы избегаете класса багов с литеральными переносами.

## `preview.py`

```bash
python3 tools/preview.py start                                   # подсказка по превью-серверу
python3 tools/preview.py check --url "http://localhost:3000/blog/<slug>"
```

`check` проверяет, что превью отдаёт HTTP 200 (код `0`) до публикации на прод. Если 500 или пусто (код `1`) - смотрите лог рендера, чините в черновике, пере-публикуйте черновик.

## Встраивание в один gate

```bash
#!/usr/bin/env bash
set -e
DRAFT="$1"; CORPUS="published/"
python3 tools/originality-check.py "$DRAFT" "$CORPUS"   # блокирующий
python3 tools/ai-cadence-check.py  "$DRAFT"             # блокирующий
python3 tools/structure-check.py   "$DRAFT"             # блокирующий
python3 tools/read-aloud-check.py  "$DRAFT" || true     # советующий
echo "Проверки пройдены."
```

## Заметки

- Все скрипты проверки понимают `.md`, `.txt`, `.html`, `.mdx` - markup и код вырезаются, считается только проза.
- Кодировка входных файлов - UTF-8.
