# Бонус: оригинальное определение навыка

Здесь лежит `original-skill-definition.md` - обезличенная версия того, как «Скилл статей» собран и работает как навык ИИ-агента в реальной эксплуатации.

**Зачем это вам.** Основной продукт (методология + автопилот + инструменты) даёт процесс. Этот файл показывает **механику навыка**: как он триггерится фразами, как ведёт себя в автономном режиме, на каких 4 gate-условиях останавливается, что читает при старте. Полезно, если вы хотите не просто пройти по методологии руками, а собрать из неё постоянный навык своего агента, который запускается одной фразой и доводит статью до публикации сам.

**Это не дубль корневого `SKILL.md`.** Корневой `SKILL.md` - живой манифест для установки (короткий, его подхватывает Claude Code). Этот файл - развёрнутое описание с философией, граничными условиями и картой 16 этапов: справочник и доказательство, что за продуктом стоит обкатанный процесс, а не теория.

Содержимое обезличено: вся специфика конкретного проекта вынесена в `config.yaml`, как и во всём продукте.
