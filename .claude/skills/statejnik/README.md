# Скилл статей

**Навык для ИИ-агента, который пишет SEO-статьи под ключ.** Вы подключаете его к своему проекту, говорите тему (или не говорите - он выберет сам по сигналам рынка), и агент проходит 16 этапов: находит тему, исследует, пишет, вычитывает шестью QA-проходами, убирает следы ИИ, проверяет рендер и публикует. На выходе - статья, которая закрывает дыру в поисковой выдаче, звучит как живой человек и ведёт читателя к вашему офферу.

Это не генератор текста «по кнопке». Это перенесённый в файлы **процесс**, обкатанный на живой контент-операции в сотни статей. Вся специфика стека и бренда вынесена в один `config.yaml` - поэтому процесс работает в любом проекте и любой нише.

---

## Запуск за 1 шаг

1. Положите папку `statejnik/` в корень проекта (в Claude Code - в `.claude/skills/statejnik/`).
2. Откройте `AUTOPILOT.md` и следуйте инструкции: вставьте промпт-установщик в агента.
3. Автопилот сам просканит проект, задаст 6 вопросов и соберёт `config.yaml`.
4. Скажите: **«напиши статью про <тему>»** - и агент пойдёт по методологии.

Без автопилота: скопируйте `config.example.yaml` в `config.yaml`, заполните руками по комментариям, и навык готов.

## Что внутри

| Папка / файл | Что это |
|---|---|
| `AUTOPILOT.md` | Промпт-установщик: изучает ваш проект и собирает конфиг за вас. |
| `config.example.yaml` | Схема конфига - единственное место вашей специфики (домен, аудитория, голос, оффер, стоп-слова, способ публикации). |
| `SKILL.md` | Манифест навыка для Claude Code: триггер-фразы + autonomous-режим. |
| `methodology/00-methodology-16-stages.md` | Сам процесс. 16 этапов в 4 фазах: Поиск → Выбор → Написание → Валидация. |
| `checklists/` | Чек-листы качества: anti-AI, SEO/GEO, конверсионная структура (CTA), соответствие (compliance), физический чек-лист на 50+ пунктов. |
| `tools/` | Скрипты проверки текста: оригинальность, читаемость вслух, детектор AI-почерка. Чистый Python 3, без зависимостей. |
| `templates/` | Скелеты заголовка, структуры и черновика. |
| `bonus/` | Оригинальное определение навыка как он работает в продакшене (white-label) - чтобы видеть реальную механику, а не только методологию. |

## 4 фазы, 16 этапов (коротко)

1. **Поиск** - пул 20+ тем из внутренних сигналов + вирусного контента за 14 дней + дыр в выдаче.
2. **Выбор** - взвешивание по 9 осям (включая вирусность), агент сам берёт победителя.
3. **Написание** - заголовок human-first (3 варианта для A/B) → deep research → структура → полный текст.
4. **Валидация** - 6 QA-агентов параллельно → цикл хуманизации до 0 AI-маркеров → визуальная проверка рендера → публикация → SEO/compliance/AI-detection аудиты → самообучение.

Каждая фаза - gate: следующая не стартует, пока не закрыта предыдущая. Подробно - в `methodology/00-methodology-16-stages.md`.

## Что нужно от вас

- ИИ-агент с доступом к файлам (Claude Code или аналог).
- Python 3 для инструментов проверки (опционально, но рекомендуется).
- 3-5 ваших текстов для тон-матчинга (опционально - без них тон нейтральный).
- Способ публикации: руками, WordPress, Ghost, Notion или свой адаптер.
