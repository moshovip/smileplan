# Рабочая тетрадь · Old School психология

Статическая страница без сборки и зависимостей.

## Как открыть

- **С диска:** открыть `psy/index.html` в браузере. Работает как есть.
- **На своём сервере:** скопировать папку `psy/` куда угодно внутрь сайта —
  все пути относительные.
- **GitHub Pages:** папка отдаётся как есть, адрес вида `…/psy/`.

Ответы хранятся в `localStorage` того браузера, где заполнялись: никуда не уходят,
но и не переезжают сами на другое устройство. Перенос — кнопками
«Сохранить копию (JSON)» и «Загрузить копию».

## Как принести расшифровку лекции

Из сессии Claude Code YouTube недоступен (egress-прокси отвечает 403), поэтому
субтитры скачиваются на своей машине:

```sh
pip install -U yt-dlp

# одна лекция
yt-dlp --write-subs --write-auto-subs --sub-langs ru --skip-download \
       --convert-subs srt -o "%(title)s.%(ext)s" "<ссылка на видео>"

# весь плейлист курса
yt-dlp --write-subs --write-auto-subs --sub-langs ru --skip-download \
       --convert-subs srt -o "%(playlist_index)02d-%(title)s.%(ext)s" \
       "https://www.youtube.com/playlist?list=PLWsL2KQ39BExodEpTCWHUtXxezWnGCPyW"
```

Файлы класть в `psy/transcripts/` (или просто прислать в чат — объём небольшой).
Запись 1997 года, автосубтитры местами врут на терминах: расшифровка нужна как
опора, спорные места всё равно перепроверяются по звуку.

## Структура

```
psy/
  index.html          оболочка
  app.js              механика: рендер, сохранение, экспорт
  styles.css          оформление, светлая и тёмная тема
  content/units.js    всё содержание тетради (единственный файл, который правится при наполнении)
  transcripts/        расшифровки лекций — источник для тем
  PLAN.md             план работ и принятые решения
```

## Как устроена тема

`content/units.js`, поле `status`:

- `stub` — заявлена, содержания нет, показывается план;
- `draft` — написано по общему знанию курса, с лекцией **не сверено**;
- `verified` — сверено с расшифровкой, файл назван в `source`.

Разобранная тема состоит из: `lead` (зачем) → `concept` (понятие) →
`notThis` (с чем путают) → `exercises` (проба на себе) → `debrief` (разбор) →
`terms` (словарь).

Типы упражнений: `text` (свободный ответ), `choice` (варианты), `scale` (шкала).
