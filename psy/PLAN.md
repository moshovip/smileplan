# Old School психология — рабочая тетрадь. План

## Что делаем

Рабочую тетрадь по курсу общей психологии В.В. Петухова (МГУ, 1997–98) — не конспект
лекций, а инструмент: понятия курса + упражнения, в которых эти понятия примеряются
на себя. Ответы остаются у автора тетради, в его браузере.

Источник: канал <https://www.youtube.com/@soulgainlibrary>,
плейлист курса <https://www.youtube.com/playlist?list=PLWsL2KQ39BExodEpTCWHUtXxezWnGCPyW>.

## Принятые решения

| Вопрос | Решение |
|---|---|
| Формат | Рабочая тетрадь: понятие → различение → проба на себе → разбор → итог |
| Угол разбора | «Ты vs понятия курса» — понятия примеряются на собственный опыт |
| Где живёт | Статика без сборки: открывается с диска, с личного сервера и с GitHub Pages |
| Источник содержания | Расшифровки лекций приносит автор (из сессии YouTube недоступен) |

## Ограничение среды, которое определило конвейер

Egress-прокси этой среды режет `www.youtube.com` (403 на CONNECT) — и для `yt-dlp`,
и для загрузки страниц. Значит, забрать субтитры отсюда нельзя в принципе, а не
«пока не настроено». Расшифровки приходят снаружи, порядок — в `README.md`.

Следствие для честности материала: у каждой темы есть статус.

- `stub` — тема заявлена, содержания нет;
- `draft` — написано по общему знанию курса, **с лекцией не сверено** (в интерфейсе
  висит жёлтая метка «черновик»);
- `verified` — сверено с расшифровкой, файл указан в `psy/transcripts/`.

Две темы уже написаны как `draft`. Это гипотеза о курсе, а не пересказ лекции;
перевод в `verified` — только после расшифровки.

## Этапы

**Э0. Каркас — сделано.**
Оболочка тетради, сохранение ответов, выгрузка в Markdown и JSON, оглавление на 18 тем,
2 темы разобраны полностью (житейская/научная психология; деятельность–действие–операция
и мотив), 16 заглушек с планом содержания.

**Э1. Конвейер расшифровок.**
Автор кладёт `.srt`/`.txt` в `psy/transcripts/`, я превращаю лекцию в тему:
тезисы → типичные смешения понятий → 4–6 упражнений → разбор → словарь.
Проверяем на одной лекции, что формат выдерживает реальный текст, и только потом
ставим на поток.

**Э2. Блоки 1–3** (вход, школы, сознание и деятельность) — ядро курса, 9 тем.
После этого тетрадью уже можно пользоваться всерьёз.

**Э3. Блоки 4–6** (познавательные процессы, личность, практика) — 8 тем.

**Э4. «Карта себя».**
Сводная тема: ответы из всех блоков собираются в один текст — повторяющиеся мотивы,
противоречия между темами. Раньше конца делать нечего: собирать нечего.

**Э5. Публикация.**
GitHub Pages и/или копия на личный сервер. Папка самодостаточна: `cp -r psy/ …` —
и работает, ни сборки, ни сервера приложений не нужно.

## Открытые вопросы

- Тетрадь только для себя или её будут проходить другие? От этого зависит,
  нужен ли обмен ответами между устройствами (сейчас — только ручной экспорт файлом).
- Порядок наполнения: по номерам лекций подряд или сначала темы, которые нужнее
  в работе (мотив, характер, защиты).

## Граница

Тетрадь учебная. Она помогает разобрать себя понятиями курса — не ставит диагноз,
не заменяет разговор с человеком и тем более терапию. Упражнения сформулированы так,
чтобы описывать, а не оценивать.
